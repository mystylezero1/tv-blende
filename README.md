## Drucken

- Alle35 STL-Dateien liegen einzeln und bereits druckorientiert vor; jedes Teil passt in180 ×180 ×180 mm.
- Profile:0,4-mm-Düse,0,20-mm-Schichten, drei Außenwände,5% Gyroid als Startwerte. Grundplatten:25% Infill.
- Profile mit schmaler Frontfacette auf dem Bett, Rückseite und Zapfen nach oben. Kein zusätzliches Fuzzy Skin.
- Zuerst Passprobe beziehungsweise Teil04 drucken. Generischer Slicertest für Teil04: rund40 Minuten; eigenes Druckprofil kann abweichen.
- Schwarz und Silber in getrennten Materialordnern; jede Datei einmal drucken.
